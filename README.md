# 캐시 바다 (Catch Sea)

부산의 해양 관광을 즐기면서 환경 보호 미션에도 참여하는 모바일 우선 웹앱 프로토타입입니다.

## 포함된 기능

- 광안리 중심의 예시 지도와 부산 장소 카드
- 조건(시간·예산·관심 분야)에 맞춘 서로 다른 미션 6개 추천
- 미션 상세, 사진·위치 인증 예시, 완료 포인트 적립
- 해양 레저·스포츠 추천과 자연어 검색창 예시
- 별점 후기 작성, 좋아요, 필터 모양의 커뮤니티
- 포인트 내역, 활동 조건 설정, 관리자 예시 화면
- 휴대폰과 노트북에서 사용할 수 있는 반응형 화면

## 파일 구성

- `index.html`: 처음 열리는 앱 화면
- `style.css`: 디자인과 반응형 화면 규칙
- `data.js`: 부산 장소·미션·레저·후기 예시 데이터
- `app.js`: 화면 전환과 버튼 기능

## 실행 방법

서버 설치가 필요 없습니다. `index.html` 파일을 내장 브라우저에서 직접 열면 됩니다.

## 예시 데이터 안내

이 프로젝트의 장소·평점·거리·금액·후기·포인트는 발표와 기능 시연을 위한 예시 데이터입니다. 실제 운영 전에는 부산시·관광 기관·사업자 정보를 확인해 바꿔야 합니다.

## GitHub Pages 배포

1. GitHub에 저장소를 만들고 이 폴더의 파일을 올립니다.
2. 저장소의 **Settings > Pages**로 이동합니다.
3. Branch를 `main`, 폴더를 `(root)`로 선택하고 저장합니다.
4. 반영에는 최대 10분이 걸릴 수 있습니다. 처음 404가 떠도 설정을 반복해서 바꾸지 마세요.

## 추후 연결할 기능

- 카카오 지도 API: 실제 지도와 장소 검색
- 위치 권한: 현재 위치 기반 거리 계산
- Supabase: 로그인, 사진 저장, 후기·포인트의 실제 저장
- 날씨·해양 기상 API: 안전한 레저 활동 추천
- 관리자 로그인: 인증 검토와 신고 관리
